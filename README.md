# Paradox Web

Community arcade, chat, art gallery & coin store.

## Setup

1. Open `js/supabase-client.js` and paste your Supabase Project URL + anon key.
2. Run `supabase/schema.sql` in the Supabase SQL Editor.
3. Open `index.html` or serve the folder locally.

See `supabase/README.md` for full instructions.
